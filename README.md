# The Ìpánu Zone

A static website for The Ìpánu Zone, a Nigerian snack shop.

## Pages and assets

- `public/index.html` is the home page.
- `public/menu.html` lists the shop's snacks and provides a phone link for orders.
- `public/css/` contains the site stylesheet.
- `public/js/` contains product data and mobile navigation behavior.
- `public/images/` contains the shop logo and snack photos.

Open `public/index.html` in a browser, or serve the `public/` directory with any static file server.
